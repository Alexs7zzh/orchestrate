# Orchestrate repo guide

Orchestrate is an interactive, master-driven DAG coordinator for herdr: validated agent-and-command
workflows run as real herdr panes. All TypeScript source lives in `scripts/` (Bun).

## Commands

```bash
cd scripts
bun run verify          # format check, lint, typecheck, dependency check, full test suite
bun run build:compile   # compiled CLI at scripts/dist/orchestrate
bun run schema          # regenerate references/*.schema.json from source types
```

## Documentation rules

- `references/guarantees.md` is the normative reliability contract. It wins over any stronger
  mechanism described in other docs; never document a guarantee there that the code does not keep.
- `references/*.schema.json` are generated by `bun run schema` — edit the source types, not the
  JSON files.
- The command table in `references/cli-spec.md` must stay in sync with `PUBLIC_COMMAND_HELP` and
  the flag sets in `scripts/src/cli.ts`.
- The minimum herdr version is defined in `MINIMUM_HERDR` (`scripts/src/herdr-surface.ts`) and
  `herdr-plugin/herdr-plugin.toml`; the only prose mentions to update on a bump are the README
  requirements list and `herdr-plugin/README.md`.
- The release contract test pins the exact payload file list (see `scripts/src/release.ts`); adding
  or removing files under `references/`, `agents/`, or `herdr-plugin/` requires updating it.
